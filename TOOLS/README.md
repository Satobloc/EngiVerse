# Tools

Reusable utilities belong here. Each tool should include:

- Purpose and supported inputs.
- Installation and environment requirements.
- Version and dependencies.
- Example invocation.
- Output schema and provenance behavior.
- Error handling and known limitations.
- Tests using non-sensitive fixtures or appropriately licensed sample data.

Keep project-specific scripts inside the relevant project until their generality is demonstrated. Prefer read-only operation on original evidence.
